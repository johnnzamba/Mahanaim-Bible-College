# Mahanaim Digital Campus — Frontend design guide

One React SPA serves the public website and every portal. This guide covers the conventions that keep
the screens consistent. Read it before adding a screen.

## Stack

React 18 · Vite 5 · Tailwind 3 · TanStack Query 5 · react-router 6 · lucide-react · recharts · socket.io-client.

## How it is served

```
browser ──► /, /about, /apply, /signin, /student/…, /admin/…   (hooks._SPA_ROUTES → website_route_rules)
            └─ mahanaim/www/mbc.py   get_context: csrf_token, boot (session_info + site settings), SEO meta
            └─ mahanaim/www/mbc.html generated by scripts/copy-html.mjs (hashed entry + css, manifest per portal)
         ──► /assets/mahanaim/app/assets/*.js|css                 content-hashed, cache-first in the SW
         ──► /api/method/mahanaim.api.*                           JSON, CSRF header, never cached
         ──► /api/method/mahanaim.api.session.service_worker      sw.js with Service-Worker-Allowed: /
```

`window.mahanaim_boot = { sitename, user, session, site, socketio_port, build }` is set before the
bundle runs, so the first paint already knows who the user is and which portals they may open.

## Layout

```
src/
  App.jsx                 router: /signin|/forgot-password|/reset-password → auth, /<portal>/* → portal, /* → public
  main.jsx                theme init, service worker, render
  portals/
    public/  PublicSite.jsx        website (PublicLayout) incl. /apply, /verify, /give, /privacy, /terms
    auth/    AuthRoutes.jsx        sign in (password + staff MFA code | one-time code), forgot (code or link) + reset
    applicant/ student/ lecturer/ admin/ sponsor/   one lazy chunk each; <Portal>.jsx is the entry
  shared/
    api/frappe.js         call/get/login/logout/uploadFile, ApiError, server-message parsing, CSRF
    api/hooks.js          useApi, useAction, useInvalidate
    api/realtime.js       onRealtime(event, handler) — socket.io, no-op for guests
    session.jsx           SessionProvider, useSession, RequirePortal, portalHome
    access.js             ROLES, ADMIN_ACCESS (admin sub-path → roles), canAccess
    brand.js              BRAND (name/motto/logo from settings), PORTALS
    theme.js              light/dark/system + rail skins (forest | parchment | ink)
    pwa.jsx               registerSW, InstallAppButton
    utils/format.js       money, num, pct, date, dateTime, time, ago, daysUntil, initials, normalisePhone…
    components/ui.jsx     primitives (Button, Input, Card, Badge, Modal, Tabs, StatCard, QueryState…)
    components/kit.jsx    composites (DataTable, Toolbar, Section, Timeline, Stepper, Board, ExportButton…)
    components/Charts.jsx TrendChart, BarsChart, DonutChart, Legendary
    layout/PortalShell.jsx  rail + header + command palette + notifications + mobile tab bar
    layout/PublicLayout.jsx website header (mega menu), announcement bar, footer
    components/OtpInput.jsx OtpInput (6 boxes, paste/autofill), useCountdown, ResendLink
    pages/AccountSettings.jsx  /<portal>/account: profile, change password, verified phone change, appearance
```

Portal folders may contain `pages/`, `components/` and a `nav.js`. A portal must not import from another
portal; anything shared moves to `src/shared/` (tell the lead).

## A portal entry

```jsx
import { Routes, Route, Navigate } from "react-router-dom"
import { LayoutDashboard, BookOpen, Wallet } from "lucide-react"
import { PortalShell } from "@/shared/layout/PortalShell"
import { lazy } from "react"

const Dashboard = lazy(() => import("./pages/Dashboard"))

const NAV = [
  { section: "Overview", icon: LayoutDashboard, items: [{ to: "/student", label: "Dashboard", icon: LayoutDashboard }] },
  { section: "Learning", icon: BookOpen, items: [{ to: "/student/courses", label: "My courses", icon: BookOpen, keywords: "units lms" }] },
  { section: "Finance", icon: Wallet, items: [{ to: "/student/fees", label: "Fees & payments", icon: Wallet, badge: 2 }] },
]
const TABS = [{ to: "/student", label: "Home", icon: LayoutDashboard }, { to: "/student/fees", label: "Fees", icon: Wallet }]

export default function StudentPortal() {
  return (
    <PortalShell portal="student" nav={NAV} tabs={TABS}>
      <Routes>
        <Route index element={<Dashboard />} />
        <Route path="*" element={<Navigate to="/student" replace />} />
      </Routes>
    </PortalShell>
  )
}
```

- Nav paths are **absolute**. Items may carry `roles` (only shown to those roles). In `/admin`, items are also
  filtered by `ADMIN_ACCESS`, so a Finance Officer never sees Exams.
- `PortalShell` already wraps children in `Suspense` and an error boundary, so pages may be lazy.
- Every portal mounts `<Route path="account" element={<AccountSettings />} />` (lazy from
  `@/shared/pages/AccountSettings`); the user menu's "Account & security" links to `/<portal>/account`.
- `serverSearch` (admin only) adds `mahanaim.api.dashboard.global_search` hits to the command palette.

## Data

```jsx
const q = useApi("mahanaim.api.student.dashboard")                       // GET, key [method, args]
const fees = useApi("mahanaim.api.fees.my_statement", { term }, { enabled: !!term })
const pay = useAction("mahanaim.api.payments.initiate_mpesa", {
  invalidate: ["mahanaim.api.fees."],     // invalidates every query whose method starts with this
  success: "Check your phone to complete the M-Pesa payment",
})
pay.mutate({ invoice, phone })
```

- Always render queries through `QueryState` (or `DataTable query={q}`), which gives the skeleton, error and
  retry, and empty states for free.
- Errors from the server (`frappe.throw`) arrive as `ApiError` with a clean `.message`; `useAction` toasts it.
- Guests: pass `{ guest: true }` for public endpoints (plain GET, cacheable). An expired session (`session_expired`
  in the response, or a CSRF error) reloads the page once; a failed sign-in (401) just shows its message.
- Uploads: `uploadFile(file, isPrivate, { doctype, docname, fieldname })` → `{ file_url, name }`.
- Real-time: `onRealtime("mbc_notification", fn)`; server publishes with `frappe.publish_realtime(..., user=…)`.

## Components (pick before you build)

| Need | Use |
| --- | --- |
| Page title + actions | `PageHeader({title, subtitle, eyebrow, actions, back})` |
| KPI | `StatCard({label, value, icon, tone, hint, delta, to})`, `MetricRow`, `Donut`, `ProgressBar` |
| Boxed section | `Panel({title, subtitle, actions, icon, footer})` or `Section` |
| Table / list | `DataTable({cols, rows \| query, rowTo, onRow, selectable, pageSize, initialSort})` + `Toolbar` + `ExportButton` |
| Status | `Badge({status})`, which picks the tone via `toneForStatus` (Paid, Overdue, Approved, Draft…) |
| People | `Avatar`, `AvatarCell`, `PersonRow` |
| Forms | `Input`, `PasswordInput`, `Textarea`, `Select({options})`, `Checkbox`, `Switch`, `RadioCards`, `FileDrop`, `Field` |
| Overlays | `Modal`, `Drawer`, `ConfirmDialog` |
| Flow | `Tabs`, `Stepper` (multi-step forms), `Timeline` (status history), `Board` (kanban) |
| Charts | `TrendChart`, `BarsChart`, `DonutChart` + `Legendary` (palette `PALETTE`) |
| Feedback | `toast.success/error/info`, `Alert`, `Empty`, `ErrorState` |
| One-time codes | `OtpInput({value, onChange, onComplete})` + `useCountdown` + `ResendLink` (`mahanaim.api.auth.request_otp` / `verify_otp`) |

DataTable columns: `{ key, label, render?(row), sortValue?(row), align?, hideOnMobile?, width?, export? }`.
Below `md`, rows become cards automatically (first visible column is the card title).

## Visual language

- **Palette**: forest green `brand-*` (primary, rail), gold `gold-*` (accent, highlights, CTAs on dark),
  cream/canvas backgrounds, `ink`/`ink-muted`/`ink-soft` text, `line` borders. Never hard-code hex colours;
  the tokens switch for dark mode and the rail skins.
- **Type**: DM Sans for UI; Libre Baskerville (`font-serif`) for page titles, hero copy and scripture.
- **Surfaces**: `.card` (rounded-2xl, hairline border, soft shadow). Use `.btn .btn-primary|gold|secondary|ghost|danger`.
- **Density**: tables `text-sm`; stat values `text-2xl font-semibold tabular-nums`; money right-aligned.
- **Status words** are fixed: Draft, Submitted, Under Review, Shortlisted, Approved, Rejected, Enrolled, Active,
  Suspended, Graduated, Paid, Partially Paid, Unpaid, Overdue, Cancelled, Published.
- **Mobile first**: every screen must work at 360 px. The mobile tab bar holds four tabs at most; heavy
  tables hide secondary columns with `hideOnMobile`.
- **Accessibility**: icon-only buttons need `label`; inputs need `label`; colour is never the only signal (pair
  it with text or an icon).

## Build and verify

```
cd frontend
npm run build      # check-refs → vite build → copy-html (commit mahanaim/public/app + mahanaim/www/mbc.html)
npm run check      # check-refs only: fails on icons/components used but never imported
npm run dev        # http://localhost:8080, proxies /api to the bench on :8010
```

The entry file is content-hashed. Never add a `?v=` query to it: lazy chunks import the bare URL, and a
second URL would evaluate the app twice and mount two React roots.
